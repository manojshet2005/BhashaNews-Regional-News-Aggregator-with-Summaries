# BhashaNews Demo Guide

## Start
1. In terminal 1: `cd backend; python seed.py; uvicorn app:app --host 127.0.0.1 --port 8000`
2. In terminal 2: `cd frontend; npm install; npm run dev -- --host 127.0.0.1`
3. Open `http://127.0.0.1:5173`

## Verified journey
1. Open the home dashboard and review the 30 demo articles.
2. Filter by a language.
3. Open a category from the top category navigation.
4. Search for a term such as `digital`.
5. Open an article detail page.
6. Review the prewritten summary and source attribution.
7. Bookmark the article and open the Saved page.
8. Refresh the browser to verify local bookmark persistence.
9. Resize the browser to mobile dimensions.

## API
- `GET /api/health`
- `GET /api/articles`
- `GET /api/articles/{id}`
- `GET /api/categories`
- `GET /api/languages`
- `GET /api/articles/featured`
- `GET /api/articles/trending`
- `GET /api/search?q=...`

API documentation: `http://127.0.0.1:8000/docs`

## Known limitation
This is a local SQLite demonstration. Summaries are prewritten and are not generated by a live pretrained Transformer.
